# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for behavior changes and superpowers:verification-before-completion before claiming completion.

**Goal:** Apply the complete UI polish review to desktop and mobile creation and MV workflows without changing product behavior or API contracts.

**Architecture:** Keep existing React components and Tailwind/CSS conventions. Add responsive presentation state only where needed, using CSS media queries for layout and small React state for mobile compact controls. Preserve existing accessibility labels and add tests for visible mobile controls, status feedback, and no horizontal overflow.

**Tech Stack:** React 19, TypeScript, Tailwind v4 utilities, shared `web/src/index.css`, Vitest, Playwright.

## Scope

- Mobile topbar collapses secondary actions into a menu.
- Mobile player defaults to a compact transport and reserves safe bottom space.
- MV progress/navigation becomes a compact mobile stepper and removes duplicate hierarchy.
- Provider and loading states become explicit status cards/skeletons.
- Brand colors, radius, spacing, and text sizes move toward shared tokens.
- Desktop layout keeps current three-zone shell and existing accessibility behavior.
